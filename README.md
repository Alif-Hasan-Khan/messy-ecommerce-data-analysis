# 🛒 Messy E-Commerce Data Analysis

## 📌 Project Overview

This project analyzes a messy e-commerce sales dataset using a complete data analysis workflow.

The dataset contained several data quality issues, including:

- Missing values
- Duplicate records
- Negative values
- Incorrect data types
- Invalid text values
- Inconsistent formatting

The data was inspected, cleaned, analyzed, and visualized using Excel, Python, MySQL, and Power BI.

---

## 🛠️ Tools and Technologies

- **Excel** – Initial data inspection
- **Python** – Data cleaning and preprocessing
- **Pandas** – Data manipulation
- **MySQL** – SQL queries and data analysis
- **Power BI** – Interactive dashboard and visualization
- **Git & GitHub** – Version control and project documentation
